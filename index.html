우리 팀 공공데이터 지도

카카오맵에 연습 마커를 표시하고, CSV 자료를 불러와 우리 팀 데이터로 바꿔 보세요.

시작 전 안내
지도 SDK를 사용하려면 카카오디벨로퍼스에서 카카오맵 사용 설정을 ON으로 바꾸고, JavaScript 키와 웹앱 도메인을 등록해야 합니다. 아래 코드는 키를 아직 입력하지 않은 시작 파일입니다. 연습 위치 3개는 가상 연습 위치·실제 자료 아님입니다.

1. 지도 연결

파일 아래쪽 JavaScript에서 YOUR_JAVASCRIPT_KEY를 본인의 JavaScript 키로 바꾼 뒤 다시 배포하세요.

키를 입력하면 지도 SDK 연결을 시도합니다. 현재는 안내 화면이 표시됩니다.

2. 우리 자료 불러오기

파일은 이 브라우저 안에서만 읽습니다. 서버로 업로드하지 않습니다. 첫 행은 열 이름이어야 합니다.

CSV 파일을 선택하면 열 이름을 읽어옵니다.

3. 결과 확인

3읽은 항목
3유효 좌표
0제외 항목

좌표는 WGS84 위도(-90~90), 경도(-180~180)인지 확인하세요. 빈 값은 0으로 바꾸지 않고 제외합니다.

배포 및 키 설정 순서
① 이 파일을 index.html로 저장해 웹 호스팅에 배포합니다. ② 실제 웹앱 주소를 확인합니다. ③ 카카오디벨로퍼스에서 카카오맵 사용 설정을 ON으로 켭니다. ④ 앱의 JavaScript 키 설정에서 JavaScript SDK 도메인에 웹앱의 도메인을 등록합니다(경로는 제외, localhost는 포트 포함). ⑤ 아래 코드의 자리표시자를 JavaScript 키로 바꾸고 다시 배포합니다. REST API 키·어드민 키·Client Secret은 넣지 마세요.
